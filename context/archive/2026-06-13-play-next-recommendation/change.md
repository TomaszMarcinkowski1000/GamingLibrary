## Notes

Roadmap slice S-07. User can request a deterministic ranked list from their own library, constrained by overall game-length bucket (short < 10h / medium 10–30h / long 30h+) and biased by one of three novelty modes ("new releases" / "newly bought" / "comfort"); 100%-completed games are de-prioritized except under "comfort", and an empty result explains which constraint excluded everything. PRD refs: US-03, FR-015, FR-016, FR-018. Prerequisites (all done): F-01, F-02, S-01, S-04. Parallel with S-06.
